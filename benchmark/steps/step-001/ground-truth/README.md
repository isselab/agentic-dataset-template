# Ground truth

Store the expected feature model, folder mappings, file mappings,
fragment-level annotations, and feature interactions after this evolution
step.

Use the native Agent-HAnS/FAXE-compatible formats whenever possible. Declare
each artifact's actual format in `manifest.json`; the example JSON files are
placeholders and do not define a replacement notation.

These files describe the expected post-step traceability state. The template
does not prescribe how generated results are checked against them.
